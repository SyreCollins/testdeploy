## Overview

Extracts structured prescription data (medication names, dosages, instructions) from prescription images. OCR is asynchronous — the create endpoint returns a job ID, and the get endpoint is polled for results.

## Authentication

Requires a valid internal API key via the `X-Zam-AI-Key` header. See the [Authentication](/docs/guides/authentication) guide for details.

## Common Request Fields

Every AI endpoint accepts a standard set of top-level fields for request tracing, caller identification, actor context, authorization, and locale. See the [Common Request Structure](/docs/guides/common-request-structure) guide for details.

## Create OCR Job

`POST /v1/ai/prescriptions/ocr-jobs`

Creates an asynchronous OCR job to process a prescription image.

### When to Use

Submit a prescription image for OCR processing when a new prescription is uploaded or needs re-processing.

### Request Body

```json
{
  "input": {
    "image_reference": "backend-storage-ref",
    "prescription_id": "backend-prescription-ref",
    "callback_url": null
  }
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `input.image_reference` | string | Yes | Reference to the stored prescription image |
| `input.prescription_id` | string | Yes | Backend prescription reference |
| `input.callback_url` | string | No | URL to call when OCR completes |

### Example Request

```bash
curl -X POST http://localhost:8000/v1/ai/prescriptions/ocr-jobs \
  -H "Content-Type: application/json" \
  -H "X-Zam-AI-Key: <your-api-key>" \
  -d '{
    "actor_context": {
      "actor_type": "pharmacy",
      "actor_id": "pharm-101",
      "role": "pharmacist"
    },
    "input": {
      "image_reference": "backend-storage-ref-123",
      "prescription_id": "rx-456"
    }
  }'
```

### Response

`201 Created`

```json
{
  "request_id": "7d9827b8-9f42-4f4f-8e4a-3c4b4fd973a1",
  "status": "success",
  "workflow": "prescription_ocr",
  "result": {
    "job_id": "ocr_job_123",
    "status": "queued"
  }
}
```

## Get OCR Job

`GET /v1/ai/prescriptions/ocr-jobs/{job_id}`

Retrieves the status and result of an OCR job.

### When to Use

Poll this endpoint after creating an OCR job to check status and retrieve extracted data once processing completes.

### Example Request

```bash
curl -H "X-Zam-AI-Key: <your-api-key>" \
  http://localhost:8000/v1/ai/prescriptions/ocr-jobs/ocr_job_123
```

### Response

`200 OK`

```json
{
  "request_id": "7d9827b8-9f42-4f4f-8e4a-3c4b4fd973a1",
  "status": "success",
  "workflow": "prescription_ocr",
  "result": {
    "job_id": "ocr_job_123",
    "status": "completed",
    "fields": [
      {
        "field": "medication_name",
        "value": "amoxicillin",
        "confidence": 0.91,
        "requires_review": false
      },
      {
        "field": "dosage",
        "value": "500 mg",
        "confidence": 0.88,
        "requires_review": false
      },
      {
        "field": "frequency",
        "value": "three times daily",
        "confidence": 0.85,
        "requires_review": false
      },
      {
        "field": "duration",
        "value": "7 days",
        "confidence": 0.82,
        "requires_review": false
      }
    ],
    "overall_confidence": 0.84,
    "requires_human_review": false
  }
}
```

| Field | Type | Description |
|-------|------|-------------|
| `result.job_id` | string | OCR job identifier |
| `result.status` | string | `"queued"`, `"processing"`, `"completed"`, or `"failed"` |
| `result.fields[].field` | string | Extracted field name |
| `result.fields[].value` | string | Extracted value |
| `result.fields[].confidence` | float | OCR confidence score (0-1) |
| `result.fields[].requires_review` | boolean | Whether this field needs human review |
| `result.overall_confidence` | float | Overall OCR confidence |
| `result.requires_human_review` | boolean | Whether the entire result needs human review |

---

## Error Responses

| Code | Description |
|------|-------------|
| `200` | OCR job status retrieved |
| `201` | OCR job created |
| `400` | Validation error |
| `401` | Missing or invalid API key |
| `404` | Job ID not found |
| `500` | Internal service error |

<Tip>
  Poll with exponential backoff. Start with 1-second intervals and increase up to
  10 seconds for long-running jobs.
</Tip>

<Note>
  Fields with `requires_review: true` or `requires_human_review: true` should be
  flagged for manual verification before use in clinical workflows.
</Note>

## More Examples

### JavaScript (fetch)

```javascript
// Create OCR job
const createRes = await fetch('http://localhost:8000/v1/ai/prescriptions/ocr-jobs', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-Zam-AI-Key': '<your-api-key>'
  },
  body: JSON.stringify({
    actor_context: {
      actor_type: 'pharmacy',
      actor_id: 'pharm-101',
      role: 'pharmacist'
    },
    input: {
      image_reference: 'backend-storage-ref-123',
      prescription_id: 'rx-456'
    }
  })
});
const job = await createRes.json();
console.log(job);

// Poll for results
const pollRes = await fetch(`http://localhost:8000/v1/ai/prescriptions/ocr-jobs/${job.result.job_id}`, {
  headers: { 'X-Zam-AI-Key': '<your-api-key>' }
});
console.log(await pollRes.json());
```

### Python (requests)

```python
import requests

headers = {
    "Content-Type": "application/json",
    "X-Zam-AI-Key": "<your-api-key>"
}

# Create OCR job
response = requests.post(
    "http://localhost:8000/v1/ai/prescriptions/ocr-jobs",
    headers=headers,
    json={
        "actor_context": {
            "actor_type": "pharmacy",
            "actor_id": "pharm-101",
            "role": "pharmacist"
        },
        "input": {
            "image_reference": "backend-storage-ref-123",
            "prescription_id": "rx-456"
        }
    }
)
job = response.json()
print(job)

# Poll for results
job_id = job["result"]["job_id"]
response = requests.get(
    f"http://localhost:8000/v1/ai/prescriptions/ocr-jobs/{job_id}",
    headers=headers
)
print(response.json())
```
