## Overview

The Dosage Verification endpoint compares supplied dosage instructions against approved reference sources. It helps verify that prescribed or patient-reported dosages fall within typical ranges for the given medication and patient context.

<Note>
  This endpoint does not prescribe new doses. It only compares supplied
  instructions against references and returns an assessment.
</Note>

## Endpoint

`POST /v1/ai/dosage/verify`

## Authentication

All requests require authentication via an internal API key. See the [Authentication](/docs/guides/authentication) guide.

For common request fields like `caller`, `actor_context`, `authorization_context`, and `locale`, see the [Common Request Structure](/docs/guides/common-request-structure) guide.

## When to Use

Use this endpoint when you need to verify that a dosage is appropriate for a given patient. It is ideal for prescription validation, medication reconciliation, and clinical decision support.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `input.medication.name` | string | Yes | Medication name |
| `input.medication.strength` | string | No | Medication strength (e.g. "500 mg") |

| `input.patient_context` | object | No | Patient context for personalized verification |

## Example Response

**(See the full JSON response above.)** The response includes the dosage assessment, typical range from references, any flags or warnings, and missing context that could improve verification accuracy.

## Error Responses

| Code | Description |
|------|-------------|
| `200` | Dosage verification completed |
| `400` | Validation error |
| `401` | Missing or invalid API key |
| `422` | Invalid request body |
| `500` | Internal service error |

## Notes

<Warning>
  This endpoint does not prescribe new doses. All assessments are comparative, not
  prescriptive. Unusual or unsupported doses are flagged for review.
</Warning>

<Tip>
  For best results, provide as much patient context as possible — especially
  weight, age, and renal function — as these directly impact appropriate dosing.
</Tip>
