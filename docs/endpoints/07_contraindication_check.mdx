## Overview

The Contraindication Check endpoint identifies potential contraindications between medications and patient conditions, allergies, or other factors. It returns evidence-backed findings and flags missing context that would improve accuracy.

## Endpoint

`POST /v1/ai/contraindications/check`

## Authentication

All requests require authentication via an internal API key. See the [Authentication](/docs/guides/authentication) guide.

For common request fields like `caller`, `actor_context`, `authorization_context`, and `locale`, see the [Common Request Structure](/docs/guides/common-request-structure) guide.

## When to Use

Use this endpoint when you need to verify that a medication is safe for a specific patient given their medical history. It is ideal for clinical decision support, prescription validation, and medication reconciliation workflows.

### Request Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `input.medications` | object[] | Yes | At least 1 medication to check |
| `input.medications[].name` | string | Yes | Medication name |
| `input.patient_context` | object | No | Patient medical context |

## Example Request

```bash
curl -X POST http://localhost:8000/v1/ai/contraindications/check \
  -H "Content-Type: application/json" \
  -H "X-Zam-AI-Key: <your-api-key>" \
  -d '{
    "actor_context": {
      "actor_type": "doctor",
      "actor_id": "dr-456",
      "role": "clinician"
    },
    "input": {
      "medications": [{ "name": "ibuprofen" }],
      "patient_context": {
        "known_conditions": ["peptic ulcer disease"]
      }
    }
  }'
```

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `result.contraindications[].medication` | string | The medication with a contraindication |
| `result.contraindications[].condition` | string | The patient condition causing the contraindication |
| `result.contraindications[].severity` | string | `"major"`, `"moderate"`, or `"minor"` |

## Example Response

**(See the full JSON response above.)** The response lists each detected contraindication with the associated medication, condition, severity, clinical rationale, and supporting evidence.

## Error Responses

| Code | Description |
|------|-------------|
| `200` | Contraindication check completed |
| `400` | Validation error |
| `401` | Missing or invalid API key |
| `422` | Invalid request body |
| `500` | Internal service error |

## Notes

<Note>
  Missing patient context is reported in `missing_context` rather than silently
  ignored. Contraindications are always backed by source evidence.
</Note>

<Warning>
  High-risk findings include escalation or review metadata. Always consult a
  qualified clinician before making clinical decisions based on these results.
</Warning>
