## Overview

The Drug Information endpoint returns reliable medication information including uses, warnings, side effects, and other sections. Drug names are normalized to their generic form for consistent referencing.

## Endpoint

`POST /v1/ai/drug-info`

## Authentication

All requests require authentication via an internal API key. See the [Authentication](/docs/guides/authentication) guide.

For common request fields like `caller`, `actor_context`, `authorization_context`, and `locale`, see the [Common Request Structure](/docs/guides/common-request-structure) guide.

## When to Use

Use this endpoint when you need to display medication information from approved medical references to patients or clinicians. It is ideal for formulary lookups, patient education, and clinical decision support.

### Request Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `input.drug_name` | string | Yes | Brand or generic drug name |
| `input.requested_sections` | string[] | No | Specific sections to return (e.g. `uses`, `warnings`, `side_effects`, `dosage`). Returns all if omitted |
| `input.country` | string | No | Country code for localized information (default: `"NG"`) |

## Example Request

```bash
curl -X POST http://localhost:8000/v1/ai/drug-info \
  -H "Content-Type: application/json" \
  -H "X-Zam-AI-Key: <your-api-key>" \
  -d '{
    "actor_context": {
      "actor_type": "patient",
      "actor_id": "user-789",
      "role": "patient"
    },
    "input": {
      "drug_name": "Augmentin",
      "requested_sections": ["uses", "warnings", "side_effects"]
    }
  }'
```

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `result.normalized_drug.input_name` | string | The original drug name queried |
| `result.normalized_drug.generic_name` | string | Normalized generic name |
| `result.normalized_drug.match_confidence` | float | Confidence of the drug name match (0-1) |
| `result.sections` | object | Map of section name to content text |
| `safety.risk_level` | string | `"low"`, `"medium"`, or `"high"` |
| `safety.action` | string | Action taken by the system |
| `safety.requires_escalation` | boolean | Whether escalation is needed |
| `safety.requires_human_review` | boolean | Whether human review is needed |
| `citations` | object[] | Source-grounded citation evidence |
| `confidence.overall` | float | Overall confidence score (0-1) |
| `confidence.grounding` | float | Grounding confidence score (0-1) |
| `confidence.retrieval` | float | Retrieval confidence score (0-1) |
| `audit.trace_id` | string | Audit trace identifier |
| `audit.prompt_version` | string | Prompt version used |
| `audit.model_provider` | string | AI model provider |
| `audit.model_version` | string | AI model version |

## Example Response

**(See the full JSON response above.)** The response includes the normalized drug name, requested content sections, safety metadata, source citations, and confidence scores.

## Error Responses

| Code | Description |
|------|-------------|
| `200` | Drug information returned successfully |
| `400` | Validation error (e.g. unknown drug name) |
| `401` | Missing or invalid API key |
| `422` | Invalid request body |
| `500` | Internal service error |

## Notes

<Note>
  All drug information is sourced from approved medical references. Drug names are
  normalized to generic names for consistency. Missing or ambiguous drug names
  return a normalization error.
</Note>
