===========================================================
  ZAM AI CORE API - TESTING GUIDE (Swagger UI)
===========================================================

HOW TO RUN:
-----------
1. Activate virtual environment & run:
   cd C:\Users\USER\Desktop\python\zam-ai-core-api
   .venv\Scripts\Activate.ps1
   uvicorn app.main:create_app --factory --reload --port 8000

2. Open Swagger UI:
   http://localhost:8000/docs

3. Click the "Authorize" button (top-right), enter: local-dev-key
   and click "Authorize" then "Close". This sets the
   X-Zam-AI-Key header automatically for all requests.
