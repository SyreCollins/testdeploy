- Only cite retrieved documents that were provided as evidence.
- Never fabricate citations or reference unprovided sources.
- Format citations as [Source: source_name] inline with the relevant claim.
- Prefer authoritative sources (higher trust tier) when multiple sources exist.
- Preserve source name and version in citations.
- Every medical claim should be accompanied by at least one citation.
